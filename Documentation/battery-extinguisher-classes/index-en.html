Fires involving flammable gases, per EN 2:2005.
editorial note
Mapping trap. Under NFPA 10 the same letter denotes fires involving energised electrical equipment. The two readings are not interchangeable, so a value of C taken from a US-sourced data set must not be carried across unchecked.
